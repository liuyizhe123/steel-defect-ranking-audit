# Data

The repository does not contain the original dataset images. Download them
from the public sources below and place them in the following directories.

## NEU-DET

NEU-DET contains six hot-rolled steel-strip defect classes:

- crazing
- inclusion
- patches
- pitted surface
- rolled-in scale
- scratches

The download helper is `training/download_neu_det.py`. Place the converted
YOLO dataset at:

```text
data/NEU-DET/
  images/train/
  images/val/
  images/test/
  labels/train/
  labels/val/
  labels/test/
```

The fixed primary split is stored in `splits/neu_det_primary.csv`, with 1,077
training, 361 validation, and 362 test images. The leakage-aware 7:2:1 split is
stored in `splits/neu_det_721.csv`, with 1,260 training, 360 validation, and
180 test images.

## GC10-DET VOC mirror

The selected public mirror is:

```text
https://github.com/wyx19980727/GC10-DET-VOC
```

The mirror contains 2,306 images and 2,280 matched annotations. Twenty-six
images without annotations are excluded from supervised experiments. The fixed
70:15:15 split is stored in `splits/gc10_det_voc_mirror.csv`.

Place the converted YOLO dataset at:

```text
data/GC10-DET-VOC/
  images/train/
  images/val/
  images/test/
  labels/train/
  labels/val/
  labels/test/
```

## Split manifests

Each CSV file contains:

```text
dataset,split,image_file,label_file
```

The manifests contain file names only. They do not redistribute image content
or label content.

## Generated annotation perturbations

Box-jitter, instance-omission, and evaluation-label realization datasets are
generated by the scripts in `training/` from a clean public dataset and the
recorded random seeds. Generated perturbation summaries are provided in
`results/`.
